## Headline result: LuSE ARDL Analysis

Over 2000 to 2025, GDP growth lifts the LASI (long-run coefficient 0.233, p = 0.044), inflation pulls it down (-0.092, p = 0.017) and a weaker Kwacha goes with a higher index (1.777, p < 0.001). About 28% of any deviation from the long-run path closes each year. [Read the full analysis](luse-ardl-analysis/).
